# Napwake's Homebrew tap

Installs `kubectl napwake`, the kubectl plugin for [Napwake](https://napwake.dev), on macOS and Linux.

```bash
brew install napwake/tap/kubectl-napwake
kubectl napwake scan
```

`scan` reads your current cluster and shows what's idle and what it costs. It changes nothing in the cluster, and needs no operator.

The [plugin's docs](https://docs.napwake.dev/getting-started/kubectl-plugin/) cover the other ways to install it, and every command.
